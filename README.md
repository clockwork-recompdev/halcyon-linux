# Halcyon Linux

An Arch-based live/install ISO with a Frutiger Aero look: KDE Plasma with glossy
aqua glass, orb window buttons, blur, Oxygen icons and Source Sans 3.

## Your art goes here

    branding/assets/logo.png           square, transparent, >= 512px (or logo.svg)
    branding/assets/wallpapers/*.png   any number; default.* (or first by name) is the default

The default wallpaper also feeds the login screen, splash screens and BIOS boot menu.

## Build

    ./build.sh            # needs ~15 GB free; asks for sudo
    ./build.sh --clean    # start from scratch

The ISO lands in `out/`. Test it with
`run_archiso -u -i out/halcyon-*.iso` (from the `archiso` package; needs `qemu-desktop` and `edk2-ovmf`).

## Layout

    build.sh                    releng profile + Halcyon overlay -> mkarchiso
    profile/airootfs/           live-session only files (live user, autologin, installer icon)
    branding/PKGBUILD           halcyon-branding package (installed on live + installed systems)
    branding/share/             -> /usr/share (Plasma theme, Aurorae, colours, SDDM, Plymouth, Konsole)
    branding/etc/               -> /etc (Plasma defaults in /etc/xdg, SDDM theme selection)
    branding/bin/halcyon-install  archinstall wrapper that adds the desktop + branding
    branding/desktop-packages.txt shared desktop package list
    tools/gen_theme.py          generates the glass panel/dialog/taskbar SVGs and window decoration

## Extras

- **Omarchy keybindings**: generated by `tools/gen_keys.py` into `/etc/xdg/kglobalshortcutsrc`.
  `Super+K` shows the cheat sheet. Hyprland-only bindings (groups, scratchpad, universal copy/paste) are omitted.
- **Desktop modes**: `halcyon-mode classic|tiling|toggle` (or `Super+Ctrl+Alt+Space`) switches live between the
  floating Aero desktop and Hyprland-style tiling (Krohnkite, gaps, borderless glowing-edge windows, top bar).
- **Gaming Setup** (`halcyon-gaming`, in the app menu): pick Steam, Wine, Lutris, Heroic, MangoHud, GameMode,
  Gamescope, ProtonUp-Qt, NVIDIA driver, Zen kernel…; installs with your password via pkexec.

## Fast theme iteration (no ISO rebuild)

    ./vm.sh            # VM shares this folder with the guest
    ./dev.sh           # host: rebuild only the theme package (~4 s)
    halcyon-dev        # in the VM: install it and reload Plasma (--keep keeps the panel layout)

Boot splash, SDDM and package-list changes still need `./build.sh`.

## Discs & old PC games

Insert a disc and Halcyon AutoPlay asks what to do (or does what you chose with "Always do this"):

| Disc | Options |
|---|---|
| PC game / software (`autorun.inf`, `setup.exe`) | Install or run program (Wine), open folder |
| MS-DOS | Run in DOSBox |
| Audio CD | Play (VLC), rip (K3b) |
| DVD / Blu-ray movie | Play (VLC + libdvdcss) |
| Blank | Burn (K3b) |

PC discs install into one shared Windows environment (`~/.local/share/halcyon/windows`, Windows XP
mode) with the disc as CD-ROM drive **D:**, which follows disc swaps. 16-bit setups run through
otvdm. SafeDisc / SecuROM / StarForce discs are detected and the user is warned: that DRM can't
run on Linux, so such games need their later no-disc-check patch.

Testing in the VM (no optical drive needed):

    ./vm-disc.sh "path/to/Game Disc 1.iso"    # insert
    ./vm-disc.sh eject

## Game library & on-screen keyboard

**Halcyon Games** (`halcyon-games`) lists installed Steam games, Windows programs installed through
Wine (disc installs included), Linux games from the app menu and anything added with *Add a Game…*
(a `.exe` runs in the shared Windows environment) in a classic olive game-client window. Favorites,
hidden games and added games are kept in `~/.config/halcyon/games.json`.

`F11`, Start, or `halcyon-games --big` switches to a full-screen menu for the TV: the game's art
fills the screen and a gamepad drives it (A play, X favorite, Y search, Start back to the window).

**Artwork** comes from SteamGridDB: paste a free API key in *View → SteamGridDB artwork…* (or the
Welcome Center) and covers, heroes and logos download in the background into
`~/.cache/halcyon-games/sgdb/`.

**Controller mapping**, a la Steam Input: when a game is launched, PCGamingWiki says whether it
supports controllers and what genre it is. Games without support get a virtual keyboard and mouse
driven by the pad - *action* (WASD, mouse look) for shooters and action games, *mouse* (stick moves
the pointer) for strategy and point-and-click. Steam games are left to Steam Input. Right-click a
game → *Controller…* to pick a layout or turn it off; Guide + Back toggles it mid-game.

The **on-screen keyboard** (`halcyon-osk`, autostarted) opens with **Guide + X** on any gamepad, from
the app menu, or from the launcher's search. It types into whatever has focus through a virtual
uinput keyboard (US layout labels), takes the gamepad over while open so the game doesn't react,
and stays above full-screen games. Pad: A type, X backspace, Y space, LB shift, RB enter, B close.

Development: `games/run.sh` (launcher) and `games/run.sh osk show` run from the checkout;
`HALCYON_OSK_DEBUG=1` logs gamepad input.

## Desktop gadgets

`halcyon-gadgets` puts Windows Vista/7 style gadgets on the desktop (autostarted; *Desktop Gadgets*
in the app menu opens the gallery). Built in: Clock, Calendar, CPU Meter, Weather (Open-Meteo),
Slide Show and Feed Headlines; Clock, Calendar and CPU Meter appear on first login. Hover a gadget
for its toolbar (close, larger/smaller, options, drag); right-click for opacity and always-on-top.

Real **Windows `.gadget` files** install by double-click or *Install from file…* (ZIP or CAB).
*Install from file…* also takes a whole **gadget pack**: point it at 8GadgetPack's
`GadgetPackSetup.msi` (or a .7z/.zip of gadgets) and it installs every gadget inside, including
Windows 7's own Calendar, Clock, CPU Meter, Picture Puzzle and Slide Show. Gadgets that need
8GadgetPack's compiled Windows helper (Glassy monitors, Clipboarder) are skipped and listed.
Microsoft's gadgets are not shipped with Halcyon; users import them from a pack they have.
Gadget pages run in QtWebEngine with a runtime (`gadgets/halcyon_gadgets/shim.js`) that provides
the `System.Gadget` / `Machine` / `Time` / `Shell` / `Network` / `Sound` APIs, flyouts, settings
dialogs, `g:background` / `g:image` / `g:text`, `gimage:///` thumbnails and the IE7-isms old gadgets
lean on: `attachEvent`, `fireEvent`, callable collections, `all.tags()`, case-insensitive
`getElementById`, XML data islands, unitless CSS lengths, `filter:alpha()`, `x-gadget:///` URLs,
and COM objects with case-insensitive members (XMLHTTP, XMLDOM + `selectNodes`, FileSystemObject,
WScript.Shell, Shell.Application, Scripting.Dictionary, **WMI** for CPU/disk/network/process
monitors, a Windows Media Player stand-in on HTML5 audio). Simple VBScript helper blocks are
translated to JavaScript (`vbscript.py`). Files are served from a token-protected local server with
Windows-style case-insensitive, locale-folder lookups; `C:\Users\<you>` maps to your home, AppData
to `~/.local/share/halcyon/gadget-data`, other drive letters to mounted disks. Compiled ActiveX
controls and Windows-only services can't run.

Gadget windows are XWayland windows kept below others and out of the taskbar. Instances and
their settings live in `~/.config/halcyon/gadgets.json`; installed gadgets in
`~/.local/share/halcyon/gadgets/`.

Development: `gadgets/run.sh` runs the host from the checkout (`HALCYON_GADGETS_DEBUG=1` prints
gadget console output); `gadgets/test/LegacyTest` is a compatibility test gadget
(zip it to `LegacyTest.gadget` and install it).

## Media Center

`halcyon-mediacenter` is a 10-foot media app in the look of Windows Media Center (December 2005
build): movies and TV from a Jellyfin or Plex server, music (albums, now playing, background
playback), the Pictures folder (thumbnails, slide show), and DVDs / Blu-rays in the drive (main
title in mpv, disc menus in VLC, eject). Keyboard, remote or gamepad.

## Messenger, Navigator and the rest

- **Halcyon Messenger** (`halcyon-messenger`): Discord in a Windows Live Messenger-style window.
- **Halcyon Navigator** (`halcyon-navigator`): an Internet Explorer 7-style browser for the old web.
  `http://` goes through [Protoweb](https://protoweb.org)'s proxy (home: the iNode Gateway),
  Flash runs in the bundled Ruffle and Java applets in CheerpJ. Protoweb and live-web browsing
  keep separate profiles. Settings: `~/.config/halcyon/retro-browser.json`.
- **Halcyon Mail** (`halcyon-mail`): Windows Live Mail-style e-mail for any IMAP/SMTP account. Server
  settings are found automatically (built-in list, then Thunderbird's ISPDB); passwords go to the
  system keyring (`secret-tool`); pictures stay blocked until asked for; new mail notifies.
- **Halcyon Update** (`halcyon-update`): a Windows Update-style window for system, Halcyon, AUR
  and Flatpak updates, with history and a daily check.
- **Welcome Center** (`halcyon-welcome`): Vista's first-run window - computer details and
  getting-started tasks (install, desktop mode, gaming setup, SteamGridDB key, updates, accounts…).
  Opens at logon until *Run at startup* is unticked.

## Sounds

Every sound is synthesized - no sound files are shipped. `tools/gen_sounds.py` makes the
**Halcyon desktop sound theme** (freedesktop spec; logon/logoff, notices, errors, devices, trash,
volume…) at package build; it is the default theme and the logon/logoff sounds are on.
Halcyon Games (2012 Big Picture-style water bloops) and Media Center (WMC-style) render their
interface sounds from `games/halcyon_games/sfx.py`.

## Updates

`./release.sh` bumps the version, builds `halcyon-branding` and publishes it as a pacman
repo on a GitHub release. Installed systems have `[halcyon]` in `/etc/pacman.conf`
pointing at the latest release, so `halcyon-update` (or `pacman -Syu`) picks it up.
A daily user timer (`halcyon-update-check.timer`) notifies when updates are waiting.
